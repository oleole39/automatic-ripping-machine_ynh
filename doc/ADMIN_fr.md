Cette application n'est [pas conçue pour être exposée publiquement sur internet](https://github.com/automatic-ripping-machine/automatic-ripping-machine/issues/583#issuecomment-1261964745) et donc par mesure de sécurité elle ne doit être rendue visible sur cette instance qu'à vos utilisateurs de confiance ("admins" par exemple).

Si cette machine est dotée d'un processeur comprenant la fonctionnalité Intel QSV (Quick-Sync Video), ou d'une carte graphique avec les fonctionnalités AMD VCE (Video Coding Engine) ou NVIDIA NVENC, vous pourriez vouloir créer une configuration personnalisée afin qu'A.R.M. en fasse usage afin d'améliorer les performance du transcodage. Voici la [documentation liée du projet source](https://github.com/automatic-ripping-machine/automatic-ripping-machine/wiki/#:~:text=Hardware%20Configuration).
