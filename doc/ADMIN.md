This app is [not meant to be exposed publicly to internet](https://github.com/automatic-ripping-machine/automatic-ripping-machine/issues/583#issuecomment-1261964745) and safety-wise it should be made visible only to trusted users of this instance ("admins" for instances).

If this hosting machine has a CPU with Intel QSV (Quick-Sync Video) capability, or a GPU with AMD VCE (Video Coding Engine) or NVIDIA NVENC capabilities, you may want to create a custom configuration so that A.R.M. makes use of it to increase transcoding performances. Here is [upstream related documentation](https://github.com/automatic-ripping-machine/automatic-ripping-machine/wiki/#:~:text=Hardware%20Configuration).
